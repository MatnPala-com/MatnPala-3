# Contributing to MatnPala

First off, thank you for considering contributing to MatnPala! It's people like you that make open-source such a powerful tool for innovation.

We want to make contributing to this project as easy and transparent as possible, whether it's:
- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features

## 🛠 Our Development Process

We use GitHub to host code and accept pull requests. 

1. **Fork the repo** and create your branch from `main`.
2. If you've added code that should be tested, **add tests**.
3. If you've changed APIs, **update the documentation**.
4. Ensure the test suite passes.
5. Make sure your code lints (follows our style guide).
6. **Issue that pull request!**

## 🐛 Reporting Bugs & Suggestions

We do not use GitHub Issues for general inquiries. If you find a bug, have a suggestion, or want to discuss the architecture, please reach out to us directly via email. 

**Great Bug Reports** tend to have:
- A quick summary and/or background
- Steps to reproduce (Be specific!)
- What you expected would happen
- What actually happens

## 📏 Coding Style & Standards

- **PHP:** We follow [PSR-12](https://www.php.net/manual/en/language.oop5.basic.php) coding standards. Use strict types (`declare(strict_types=1);`) at the top of all PHP files.
- **Naming:** Use descriptive and meaningful variable/function names (preferably in English). Do not use abbreviations.
- **Comments:** Comment your code where the logic is complex. Explain *why* you did something, not *what* you did.
- **Security:** Always sanitize inputs, use prepared statements for database queries, and never expose sensitive credentials.

## 📜 Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). We expect all contributors to treat each other with respect. Harassment, toxic behavior, or discrimination will not be tolerated.
