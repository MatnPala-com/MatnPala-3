# Security Policy

## Supported Versions

We are committed to maintaining the security of MatnPala. The following table outlines which versions of the project are currently receiving security updates:

| Version | Supported          | Notes |
| ------- | ------------------ | ----- |
| 3.x.x   | :white_check_mark: | Active development and security patches. |
| 2.x.x   | :x:                | End of life. No security updates. |
| 1.x.x   | :x:                | End of life. No security updates. |
| < 1.0   | :x:                | End of life. No security updates. |

*Note: Since MatnPala 3 is the current stable release, all security patches will be applied exclusively to the 3.x.x branch.*

## Reporting a Vulnerability

We take the security of our users' data and our open-source codebase very seriously. If you discover a security vulnerability in MatnPala, we appreciate your help in disclosing it to us in a responsible manner.

**Please do NOT report security vulnerabilities through public GitHub issues.**

### How to report:

1. Send an email to **info@refinetext.ir** with the subject line: `[SECURITY VULNERABILITY] - MatnPala`.
2. Include as much detail as possible in your report:
   - A description of the vulnerability.
   - Steps to reproduce the issue (proof of concept).
   - The potential impact (e.g., data exposure, denial of service).
   - Any suggested fixes or mitigations (if applicable).

### What to expect:

- **Acknowledgment:** You will receive an acknowledgment of your report within **48 hours**.
- **Assessment:** We will investigate the issue and determine its severity and impact.
- **Resolution:** If the vulnerability is confirmed, we will work on a patch and release a security update as quickly as possible.
- **Disclosure:** We will coordinate with you regarding the public disclosure of the vulnerability once a fix has been deployed.
- **Credit:** If you wish, we will publicly credit you for discovering and responsibly disclosing the vulnerability in our release notes.

We ask that you give us a reasonable amount of time to address the issue before making any information public.

Thank you for helping keep MatnPala and its users safe.
